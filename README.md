# Student Sales Analysis Project

## Project Objective
This project uses Microsoft Excel to analyze sales data, review customer performance, understand sales and profit trends, and present findings with charts and a dashboard.

## Assignment Topics
- Conditional Formatting
- What-If Analysis
- Linear Regression (Profit vs Sales)
- Descriptive Statistics and Data Analysis ToolPak
- Monthly sales growth with up/down arrows
- Timestamp using `NOW()`
- High-value customer analysis using `INDEX`, `MATCH`, and filters
- Sales analysis by region and product
- Bar, line, and pie charts
- Dashboard and data storytelling

## How to Use
1. Open the Excel workbook in Microsoft Excel.
2. Allow formulas to recalculate when prompted.
3. Review the customer, monthly, analysis, chart, and dashboard worksheets.
4. Check that the workbook's formulas and charts match your assignment instructions before submitting.

## Important Notes
- The `NOW()` function changes when Excel recalculates the workbook.
- If your instructor specifically requires official Analysis ToolPak output, generate Regression and Descriptive Statistics using Excel's **Data > Data Analysis** menu.
- If a native PivotTable is specifically required, create or refresh it in Excel using **Insert > PivotTable** and choose the appropriate Region, Product, and Sales fields.
